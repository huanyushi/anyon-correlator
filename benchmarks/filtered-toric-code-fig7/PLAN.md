- 无限平面，四自旋对角 blocking，Pauli convention，过滤算符为 exp[(βxX+βzZ)/4]。
- Fig.6 读出的 (βz,βx)：a=(.55,.45)，b=(.8,.45)，c=(1.05,.45)，d=(1.3,.45)，e=(.45,.55)，f=(.45,.8)，g=(.45,1.05)，h=(.45,1.3)。参数来源为论文图中的标记坐标。
- 本地单线程，累计计算预算10800秒；每点保存张量、边界、谱、参数与进度。旧结果及旧程序不覆盖。
- 拓扑相保留对角 Z₂；charge condensed 相允许完全破缺；flux condensed 相保留 Z₂×Z₂，分别标记两层 charge。
- 低残差只说明有限χ的局部求解情况；必须结合群作用后的边界重叠及谱结构解释物理相。
- domain-wall 的相对逐格相位影响动量约定，明确记录；谱量按背景每格主导尺度归一化。
